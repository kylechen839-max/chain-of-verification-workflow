# Benchmark Inputs

Benchmark question sets are grouped by filename lineage:

- `cove_benchmark_questions*.json` are early/general benchmark prompts.
- `cove_benchmark_questions_nasa_*.json` are NASA article metadata prompts generated before the Supabase-question table was added.
- `cove_benchmark_questions_supabase_*.json` are exported Supabase-question prompts with reference-source metadata for validation.

The current corrected Supabase results are under `results/by_workflow/03_supabase_corrected_current/`.
